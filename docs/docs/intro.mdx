Sibyl brings your exchange accounts, market research, trading experiments, and AI specialists into a single local workspace. A React interface talks to a Python API; [ProtoLink](https://github.com/nMaroulis/protolink) runs every module agent.

Start with [installation](getting-started/installation.md), explore the [portfolio](guides/portfolio.md), or learn how to [give Oracle a language model](guides/oracle.md).

## A workspace with a point of view

| Module         | What it does                                                   |
| -------------- | -------------------------------------------------------------- |
| Accountant     | Holdings, allocations, portfolio valuation, CSV exports        |
| Analyst        | Daily indicators, price charts, volatility, correlations       |
| Broker         | Backtests, persistent paper strategies, reviewed manual orders |
| Chronos        | A statistical price baseline with uncertainty bands            |
| Reporter       | Source-linked news and module briefings                        |
| Technician     | Encrypted exchange connections and credential checks           |
| Wiki           | Crypto education through a curated glossary                    |
| Explorer       | Recent Bitcoin blocks                                          |
| Equity Analyst | Equity quotes and adjusted daily history                       |
| Oracle         | A portfolio-focused entry point to the specialist workspace    |

## Three distinctions to keep in view

**Demo and live data.** The default demo workspace uses deterministic illustrative data. Live mode reads exchange APIs and research providers. Every view identifies its source, and failed live requests do not become sample data.

**Paper and exchange execution.** Manual paper orders and strategy jobs use virtual funds. Exchange orders require a separate server setting, exchange permissions, a fresh review, and typed confirmation. Agent tools are read-only.

**Tools and language models.** All agents use ProtoLink. With no model configured, the agent executes its native tool and returns a factual snapshot. A configured model can interpret tool observations and the conversation. The UI labels which mode produced each response.

## Scope of this release

This is a single-user spot-crypto workspace. It includes six strategy algorithms, configurable closed-candle market data, source-linked research, and optional model inference. It does not include derivatives, withdrawal access, continuous exchange strategy execution, Freqtrade, senate trading archives, SHAP, regression workbenches, a trained forecast model, or an embedding-based RAG service. Planned additions are labeled **Coming soon** in each module and listed in [Feature coverage](guides/feature-coverage.md); the [extension guide](developers/extending.md) explains where they belong.
