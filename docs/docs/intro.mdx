Sibyl brings your exchange accounts, market analysis, trading, strategy research and AI specialists into one workspace you can run locally. A React interface connects to a modular Python API, while [ProtoLink](https://github.com/nMaroulis/protolink) powers Sibyl and its specialist team.

These guides describe **v2.1.0**, building on the v2.0.0 application baseline. Read the [changelog](changelog.md), start with [installation](getting-started/installation.md), or explore the [architecture](developers/architecture.md).

## Start with your accounts, or take a look around

New workspaces have **no active accounts**. Connect one or many exchanges in Settings, then view them together or individually in Account. The smaller **Preview with Demo** option activates a labeled virtual account; activating an exchange turns Demo off. Public market and research sources have independent settings, so you can explore them without activating an account.

## An AI team alongside the tools

Sibyl discovers ten module specialists through ProtoLink and consults them as needed. Page-level **Ask** dialogs speak directly with the relevant specialist. Agents use typed read-only domain tools, saved conversations and native execution evidence.

Configure an API or local model in [AI models](guides/settings.md) to enable reasoning and the Sibyl coordinator. Specialists also offer factual tool mode without a model. The [Telegram client](guides/telegram.md) can connect a configured private user to Sibyl; the other messaging channels are clearly unavailable setup previews.

## Know the source and the scope

Demo, paper, test environments and production observations are labeled separately. Provider failures remain visible. Exchange capabilities vary by adapter and are shown in Settings; code support and [authenticated acceptance](developers/exchange-acceptance.md) are documented separately.

Manual exchange orders and automated strategies require their applicable server flags, permissions and scoped approvals. Agent tools remain read-only. Trained forecasts retain held-out evidence and empirical calibration limits; the untrained baseline remains separate. Sentiment describes supplied text, and technical scores expose their mechanical rules.

Sibyl currently runs as **one user and one API worker**. The [feature overview](guides/feature-coverage.md), [security guide](guides/security.md) and [pending checklist](developers/backend-roadmap.md) explain the current boundaries and planned extensions.
