## Differences from the old application

The old saved TensorFlow models are not loaded into the current runtime. Forecasts are labeled **Untrained baseline**. The Wiki does not pretend that a glossary is a document retrieval system. Only market orders are executable. Strategy jobs use separate virtual funds even when market data is live. News scores describe the supplied text, not investor positioning.

Existing strategy algorithms are reimplemented as explicit Python rules. New default parameters are documented, and historical results should be treated as new simulations. No legacy database or model migration is required.

## Source and scope boundaries

Demo mode always labels fixtures. Live mode reports provider failures rather than replacing them with samples. Live exchange behavior is adapter-dependent and must be verified against each account and venue. Paper P&L is limited to locally retained, matched manual trades; it is not a tax report. Exchange intent prices/notionals are labeled reference values, not final settlements. The strategy console owns its separate fills and results.
