## Differences from the old application

The old saved TensorFlow models are not loaded into the current runtime. Forecasts are labeled **Untrained baseline**. The Wiki does not pretend that a glossary is a document retrieval system. Market and GTC limit orders are executable within the documented provider allowlist. Strategy jobs use separate virtual funds even when market data is live. News scores describe the supplied text, not investor positioning.

Existing strategy algorithms are reimplemented as explicit Python rules. New default parameters are documented, and historical results should be treated as new simulations. No legacy database or model migration is required.

## Source and scope boundaries

Demo mode always labels fixtures. Live mode reports provider failures rather than replacing them with samples. Live exchange behavior is adapter-dependent and must be verified against each account and venue. Paper P&L is limited to locally retained, matched manual trades; it is not a tax report. Exchange intent prices/notionals are labeled reference values, not final settlements. The strategy console owns its separate fills and results.

Retained account FIFO in **Trade → Account history → Performance** is distinct from the local paper report. It excludes unknown-cost sales, suppresses final net results for unresolved coverage and keeps each quote currency/environment separate. See [performance boundaries](../developers/account-performance.md).

Funding history now has Binance crypto deposit/withdrawal imports, Kraken deposit/withdrawal/transfer ledger imports and Bybit on-chain withdrawal imports, explicit date ranges, resumable progress, native-asset completed summaries and ProtoLink Accountant evidence. Additional providers, comprehensive cash events and account-wide balance reconciliation remain pending. See [funding coverage](../developers/funding-history.md).

Transfer review adds bounded suggestions, manual retained-record search, explicit own-account assertions, current/saved source evidence, audit and reversible removal/restoration. Source corrections flag links for review. Transfer-aware cost-basis accounting and complete external-funding classification remain pending. See [transfer review](../developers/transfer-reconciliation.md).

Performance carries original FIFO lots for eligible equal-amount, explicitly zero-fee confirmed transfers, with dependency-aware account filters, original-lot evidence and unapplied reasons. Reviewed balanced same-asset fee allocations also carry lots and expose separate fee-unit inventory cost. Historical fee valuation, split/merged carryover, other fee currencies/rebates, cross-market basis and cash-flow-adjusted account returns remain pending. See [transfer cost basis](../developers/transfer-cost-basis.md).

**Multi-user hosting is deferred.** The current scope remains one local user and one API worker. Agents, Alerts, Research and Coming soon are under **More**. See [the audited pending inventory](../developers/backend-roadmap.md).

Markets now includes a persistent source/environment/pair/timeframe archive, reviewed resumable historical imports, gap coverage, retention and immutable research inputs. Both chart modes support bounded zoom/pan/inspection/volume without an added dependency. Backtests retain their inputs and can replay saved datasets offline. Remaining market foundations are broader import adapters, shared budgets/health diagnostics and WebSockets. See [history coverage and limits](market-history.md).

The combined Order monitor also includes read-only open/recent [exchange order discovery](../developers/order-discovery.md) for reviewed clients, filters before pagination, saved progress and shared fill evidence. Remaining scope includes additional providers, amendments, authenticated acceptance and definitive settlement.

## Sibyl collaboration

The dedicated Sibyl chat discovers module agents through the startup ProtoLink registry and consults them through agent clients. It requires an API/local model, supports saved local conversations and displays actual consultation evidence. Live progress, request-specific Stop and retained completed/stopped/failed/interrupted request outcomes are implemented. Token streaming and scheduled/resumable investigations remain pending. Module Ask dialogs retain direct specialist access and factual tool mode. Telegram is available with private-user binding, encrypted setup and durable delivery; other messaging integrations remain unavailable previews. See the [Sibyl guide](./sibyl.md).
